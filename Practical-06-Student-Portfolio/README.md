# Practical 06: Student Portfolio Application

## Objective
Create an Angular single-page application to display a comprehensive student portfolio including Personal Bio, Technical Skills, Academic Projects, and Contact Information.

---

## 💡 Concept Explanation
Demonstrates structured object binding, arrays of objects, and dynamic card rendering with responsive CSS styling in Angular.

---

## 📂 Source Code Structure
- [`src/app/app.component.ts`](./src/app/app.component.ts): Data model containing student profile info, skills, projects, and contact channels.
- [`src/app/app.component.html`](./src/app/app.component.html): Structured semantic markup with modular sections.
- [`src/app/app.component.css`](./src/app/app.component.css): Modern CSS styling with card containers, skill badges, and hover animations.
