# Practical 02: Angular Certification Activity

## Objective
To complete an online technical certification on **Angular Basics** through **SkillUp by Simplilearn**, reinforcing foundational concepts of frontend architecture, component lifecycles, and TypeScript integration.

---

## 📌 Activity Details
- **Course Name:** Learn Angular Basics (SkillUp by Simplilearn)
- **Duration:** Approx. 3 Hours (Self-paced video modules + quizzes)
- **Official Portal Link:** [https://www.simplilearn.com/learn-angular-basics-free-course-skillup](https://www.simplilearn.com/learn-angular-basics-free-course-skillup)

---

## 📝 Learning Modules Covered
1. Introduction to Angular Framework and Architecture
2. Angular CLI setup and project structure
3. TypeScript fundamentals for Angular
4. Components, Templates, and Data Binding
5. Directives (Built-in Structural and Attribute directives)
6. Services and Dependency Injection
7. Routing and Navigation basics
