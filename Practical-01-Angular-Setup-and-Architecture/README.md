# Practical 01: Angular Setup, CLI & Core Architecture

## Objective
To understand the prerequisites, installation procedure, and core foundational architecture of the Angular framework including Components, Decorators, and Data Binding mechanisms.

---

## 🛠️ Installation & Environment Setup
Refer to [installation-guide.md](./installation-guide.md) for full commands on Ubuntu Linux and Windows.

### Quick Commands:
```bash
# 1. Install Node.js (v20+ LTS recommended)
node -v
npm -v

# 2. Install Angular CLI Globally
npm install -g @angular/cli
ng version

# 3. Create a new Angular Project
ng new my-angular-app

# 4. Run the Dev Server
cd my-angular-app
ng serve
```
