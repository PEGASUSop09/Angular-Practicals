## 🚀 How to Run Any Practical Locally

### Prerequisites
1. **Node.js** (v18.x or v20.x recommended):
   ```bash
   node -v
   npm -v
   ```
2. **Angular CLI** (Globally installed):
   ```bash
   npm install -g @angular/cli
   ng version
   ```

### Running a Component
1. Create a workspace or use an existing Angular project:
   ```bash
   ng new angular-practicals-app --defaults
   cd angular-practicals-app
   ```
2. Copy the contents of the desired practical (`src/app/*`) into your app's `src/app/` folder.
3. Start the Angular development server:
   ```bash
   ng serve
   ```
4. Open your browser and navigate to:
   ```
   http://localhost:4200
   ```
